# Para ti, con todo mi amor

Una carta de cumpleaños estática y adaptable a móviles. Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor de archivos estáticos. Las siete fotografías están incluidas en `assets/photos/`.

No hay reproducción automática ni pista de audio incluida. El visor de recuerdos se puede cerrar con Escape y navegar con las flechas del teclado.
